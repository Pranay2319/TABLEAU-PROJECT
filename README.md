# TABLEAU-PROJECT
Grocery Sales Performance and Customer Segmentation Analysis Using Tableau
This project uses Tableau Desktop to analyze grocery sales, profit, discount impact, and customer purchasing behavior. It includes sales and profit visualizations, regional maps, sales trends, Profit Ratio analysis, and interactive Region and Category filters. Customer behavior is analyzed using RFM metrics, clustering, scatter plots, and high-value customer identification to create an interactive customer segmentation dashboard.
